## Historical essay

Thomas Malthus' 1798 essay, "On the principle of population".
At the time it was first published the descending "s" was in fashion.
This reconstruction uses ligatures and the 'text-replace' property to
recreate the original printed book. The table of contents is generated
with a script.

(Archive.org) has a scanned copy of the work.

### Instructions

Build the sample as follows:

```
prince -j essay.html
```
