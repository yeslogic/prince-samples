## Book excerpt

An excerpt from "Cascading Style Sheets, designing for the Web,"
by Håkon Wium Lie and Bert Bos, 3rd edition.

This book was the first printed book written in HTML and CSS. The sample
document contains the frontmatter and first chapter.


### Instructions

Build the sample as follows:

```
prince sample.html
```

A second excerpt can be built as follows:

```
prince cssdftw.html
```
