## Newsletter example

A newsletter from [Drylab](https://www.drylab.no/), converted to HTML/CSS.

### Instructions

Build the sample as follows:

```
prince drylab.html
```

### Credits

Drylab has kindly allowed this newsletter to be redone in HTML/CSS and
converted to PDF with [Prince](http://www.princexml.com).
[Navngen](http://navngen.no/) helped anonymize names in the process.
